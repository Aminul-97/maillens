Project Name: MailLens
Description: MailLens is a project for deep email validation, consisting of a Chrome extension and a verification API.

## Project Structure
- `maillens-api`: Contains the API that uses "deep-email-validator". The plugin uses this API to validate emails.
- `maillens-plugin`: Contains the Chrome extension plugin. Makes the necessary API calls to the API.
